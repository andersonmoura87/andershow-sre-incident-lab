# Contribuição e revisão

1. Abra uma issue para cada incidente ou melhoria documental.
2. Use branches `docs/inc-XXX-...` ou `feat/...` e commits em português.
3. Não altere evidências originais para fazer o resultado parecer melhor.
4. Faça revisão de segredos, URLs com tokens e identificadores antes do push.
5. Verifique links locais, Markdown e consistência entre evidências e conclusões.
6. Pull requests devem informar objetivo, alterações, evidências e limitações.
